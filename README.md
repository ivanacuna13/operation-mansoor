# Operation Mansoor

Documentation and editable XML corpus for the Operation Mansoor content-production system.

This public repository is a documentation-focused snapshot of the Mac Mini workspace. It includes Markdown instructions, runbooks, status notes, QC records, and XML edit timelines. Raw video, audio, project caches, databases, runtime state, logs, exports, and credentials are intentionally excluded.

## Layout

- `mansoor-content-operations/` — Content OS documentation, skills, reviews, audits, and operating rules.
- `MVE_PROJECT_SYSTEM/` — Master Video Editor project/batch docs + bridge notes.
- `mve-adobe/` — Adobe worker documentation and setup notes.
- Project folders — build logs, delivery notes, QC documentation, and XML timelines where available.

## Notes

- Live pipeline source of truth remains outside this repository.
- Videos, audio, backups, generated renders, and local machine state are not included.
