# Skill — message engineering

## Use when

Compressing an approved candidate into a high-value standalone message.

## Method

1. Freeze the promise and delivery anchors.
2. Label each sentence or phrase: `essential`, `supporting`, `redundant`, `filler`, `example`, `transition`, or `context-dependent`.
3. Remove filler and redundant variants first.
4. Remove incomplete examples. If examples merely reinforce an already clear sentence, keep at most the strongest one—or none when space/value does not justify it.
5. Remove additive setup phrases that only announce the coming value.
6. Collapse repeated formulations into the cleanest phrasing already spoken.
7. Read the engineered transcript cold. Restore any missing causal or grammatical bridge.
8. Confirm the final sentence fulfills the opening promise and lands cleanly.

## Guardrails

- Never rearrange words into a claim the speaker did not make.
- Never cut away a qualifier that changes truth conditions.
- Do not chase a duration number. The tutorial reduced roughly 86 seconds to 44 seconds because the extra material was unnecessary, not because 44 seconds is a rule.
- Log each nontrivial deletion and its reason.
